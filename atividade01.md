# Atividade 01

1. Explique, com suas palavras, o que é machine learning?

   É uma forma de ensinar o computador com vários dados, para que ele use vários cálculos matemáticos sobre esses dados e, assim, possa dar uma resposta.

2. Explique o conceito de conjunto de treinamento, conjunto de validação e
conjunto de teste em machine learning.

    Usado muito no aprendizado supervisionado, o conjunto de treinamento serve para ensinar ao computador, onde ele vai usar cálculos matemáticos para encontrar padrões. Já o conjunto de validação é usado para ajustar hiperparâmetros, e, por fim, o conjunto de teste serve para avaliar o modelo final.

3. Explique como você lidaria com dados ausentes em um conjunto de dados de treinamento.

    Analisaria os dados e tentaria usar alguns cálculos estatísticos para substituir esses valores faltantes. Se não for possível, teria que eliminar as linhas onde há valores faltantes.

4. O que é uma matriz de confusão e como ela é usada para avaliar o
desempenho de um modelo preditivo?

    É usado para visualizarmos os valores de falso-positivo, falso-negativo, verdadeiro-positivo e verdadeiro-negativo, e, com isso, avaliamos o modelo.

5. Em quais áreas (tais como construção civil, agricultura, saúde, manufatura,
entre outras) você acha mais interessante aplicar algoritmos de machine
learning?

    Segurança pública com a predição de crimes e câmeras inteligentes, cidades inteligentes com vários dados gerados e no setor aeroespacial para gerar vários insights.
